## 我们收集什么

| 类别 | 内容 | 用途 | 法律依据（GDPR） |
|---|---|---|---|
| 注册信息 | 邮箱、手机（可选）、密码（哈希）| 创建账号、登录 | 合同履行 |
| 计费信息 | 充值记录、消费记录、余额 | 计费、税务、对账 | 合同履行 + 法定义务 |
| 元数据日志 | 时间戳、模型、token 数、调用 IP（脱敏 /24）| 风控、计费、SLA | 合同履行 + 合法利益 |
| 调用内容（可选）| Prompt / Response | 仅在您开启"调试模式"时存储 ≤24h | 同意 |
| Cookie / LocalStorage | 会话 token、UI 偏好 | 必需 cookie | 合法利益 |

**默认情况下，我们不存储您的 Prompt 与 Response 文本**。仅当您主动开启"调试模式"，或经特定司法机关要求时才存储。

## 我们不做什么

- ❌ **不卖数据**给第三方广告商
- ❌ **不用您的对话训练我们的模型**（我们没有自训模型）
- ❌ **不与上游 LLM 提供方共享**超出"代理调用"必需的数据

## 数据传输给谁

- **上游 LLM 提供方**（OpenAI / Anthropic / Google 等）：**您的 prompt 必然要发送给上游模型**才能产生 response。这部分由上游 ToS 与隐私政策管辖
- **支付服务商**（Stripe / 易支付）：仅传递充值订单元数据
- **基础设施供应商**（Cloudflare / AWS / 阿里云等）：传输与存储中间环节
- **法定/司法机关**：经合法传票/法院令我们将依法配合

跨境传输：上游 LLM 服务多在美国境内 → 您的 Prompt 在调用过程中**会传到境外**。
- EU 用户：依靠 SCCs（Standard Contractual Clauses）+ 上游服务方的等同保障
- 中国用户：上游传输属于"必要传输"，**请勿提交个人敏感信息**

## 您的权利

依据 GDPR / CCPA / 中国《个人信息保护法》：

| 权利 | 操作入口 |
|---|---|
| 访问 / 副本 | 个人中心 → "导出我的数据" 或写信 [[privacy@example.com]] |
| 更正 / 修改 | 个人中心 → 修改资料 |
| 删除 | 个人中心 → "注销账号"（30 天宽限期）|
| 限制处理 | [[privacy@example.com]] |
| 反对处理 | [[privacy@example.com]] |

| 投诉权 | 您所在地数据保护机关 |

我们承诺在 **30 天**内响应（GDPR 要求 1 个月，复杂请求可延长 2 个月）。

## 安全措施

- TLS 1.3 全链路加密
- 数据库加密（at rest + at transit）
- API Token 加盐哈希存储
- 上游 Key 用 HashiCorp Vault 加密
- 季度密钥轮换
- 24/7 异常检测与告警
- 详见 [`security/`](../security/)

## 未成年人

本服务**不面向 18 岁以下**用户。如发现未成年用户，我们会立即关闭账号并删除数据。

## Cookie 政策

我们仅使用**严格必要 Cookie**（会话 / 反 CSRF）和**功能 Cookie**（语言、主题）。
不使用第三方追踪 Cookie，不嵌入 Google Analytics 等分析脚本（如启用，会单独取得同意）。
