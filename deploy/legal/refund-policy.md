# Refund Policy / 退款政策

> 🚧 模板。Version: 1.0.0 / 2026-04-27

## 总则

本政策规定向 [[公司名]] 的付费充值的退款规则。

## 默认规则：充值不退、消费不退

由于本服务为**实时按用量计费的预付制**：
- **未消费余额不可退**（已支付即视为完成购买预付服务）
- **已消费余额不可退**（按实际转发到上游的请求即时计费）
- **兑换码不可退**（生成后视为完成购买）

## 例外：可退情形

我们在以下情况会**全额或部分退款**：

### A. 双方协商退款（无过错）

| 情景 | 处理 | SLA |
|---|---|---|
| 充值后 **24 小时内** 未消费一分钱 | 全额退款（扣除支付通道手续费 ~3%）| 5 工作日 |
| 误操作充值（明显多冲，如目标 $10 但充了 $1000）| 退超额部分（扣手续费）| 5 工作日 |
| 上游服务连续 7 天不可用导致服务无法使用 | 按比例退当月已充未用部分 | 14 工作日 |

### B. 我方过错

| 情景 | 处理 |
|---|---|
| 因平台 bug 多扣费 | 全额退多扣部分 + 等额代金券 |
| 因平台过失泄露您的账号 | 退本月已充未用 + 个案补偿 |
| 我方单方下线服务 | 退所有未消费余额 + 提前 30 天通知 |

### C. 法定退款（如适用）

EU 用户依据《消费者权利指令》享有 **14 天冷静期**：
- 未使用任何 token 的纯充值，可在 14 天内无理由退款（扣手续费）
- 一旦消费哪怕 1 个 token，即视为"开始数字内容服务"，**冷静期失效**

加州 CCPA 项下不强制退款，依本政策执行。

## 不退款情形

下列情况**严格不退**：

- 您因违反 ToS / AUP 被封号
- 您主动注销账号（注销前请用完余额）
- 上游平台短期波动（< 7 天 / SLO 内）
- 第三方原因（您所在地的网络、CDN 中断等）
- 兑换码被泄漏后被他人使用（请妥善保管）
- 充值超过 90 天的"沉睡余额"（此时已纳入会计收入）

## 退款流程

### 1. 提交退款申请

- 入口：账户中心 → 钱包 → "申请退款"
- 备用：邮件 [[refund@example.com]] 附以下信息：
  - 注册邮箱
  - 充值订单号（在"账单"页可查）
  - 退款原因
  - 期望金额

### 2. 审核

- **首次响应 24 小时内**
- 风控复核：检查账号是否有违规、是否同 IP 多账号刷退款等
- 必要时要求补充：身份证明、付款截图

### 3. 退款执行

- 原路退回（信用卡 / Stripe / 易支付 / USDT 等）
- 通常 **5 个工作日**内到账（信用卡可能 7-14 天）
- 跨境退款可能产生汇率差与手续费，由您承担
- 退款时**冻结对应账户余额**，避免出现"退款后还能用"

### 4. 通知

退款完成会发送邮件确认，含退款金额、订单号、到账估计。

## 争议处理

如对退款决定有异议：
- 第一步：在拒绝邮件回复 7 天内提出申诉
- 第二步：升级到客户成功经理（[[csm@example.com]]）
- 第三步：根据 ToS 走仲裁程序

## 反欺诈

我们可能**拒绝**或**冻结**以下退款请求：
- 同一身份/支付源 90 天内 3 次以上退款
- 通过黑卡 / 偷盗信用卡 / 洗钱通道充值
- 用充值 + 退款洗换支付通道
- 在论坛 / Telegram / Discord 公开教唆"先充再退"套利

涉嫌欺诈的退款，会冻结相关订单 **30 天**调查，必要时报警。
