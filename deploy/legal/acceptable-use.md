# Acceptable Use Policy / 可接受使用政策（AUP）

> 🚧 模板。Version: 1.0.0 / 2026-04-27

## 总则

本 AUP 是《服务条款》的组成部分。违反 AUP 等同违反 ToS，我们可立即暂停或终止您的账号，**已支付费用不退**。

## 严格禁止使用本服务做：

### 一、违法或侵权

- 任何**违反您所在地或服务器所在地法律**的活动
- 制作、传播 **CSAM**（儿童性虐待材料）— 一经发现立即报警并配合调查
- 侵犯他人**版权 / 商标 / 商业秘密** / 肖像权 / 隐私权
- 协助**洗钱 / 逃汇 / 非法集资 / 庞氏骗局**
- 协助**毒品交易 / 武器交易 / 人口贩卖**
- **未经授权**访问他人系统、数据、账户

### 二、危害公共安全

- 制造**生物化学武器**、爆炸物、核武器、3D 打印枪支等
- 网络攻击：DDoS、勒索软件、僵尸网络、钓鱼工具开发
- 自动化大规模身份伪造（包括 deepfake 用于欺诈）

### 三、对人的伤害

- 鼓励 / 指导**自杀、自残、饮食失调**
- 针对个人或群体的**骚扰、跟踪、人肉搜索（doxxing）**
- 基于种族 / 性别 / 宗教 / 取向的**仇恨言论与煽动暴力**
- 制造涉及真实可识别人物的**性化内容**（不含成年人本人书面同意的合法 NSFW）

### 四、欺诈与误导

- 冒充政府 / 客服 / 银行 / 平台
- 制造虚假新闻、虚假评论、虚假学术（用于学术不端）
- 自动化操纵选举、舆论
- 用于"AI 答题代考" — **多数高校与认证机构属作弊**

### 五、滥用本服务

- 以任何方式破坏服务（DoS、SQL 注入、撞库等）
- 共享单个账号给多人使用以规避计费
- 利用本服务的**漏洞牟利**而不报告（请走 Bug Bounty）
- **倒卖 / 二次代理**本服务的 API（如建立 "X中转站" 转卖）
- 自动化**抓取**（含但不限于嵌入向量、模型回答用于训练）

### 六、敏感行业的特殊限制

以下场景**需事先书面授权**才能使用：
- 医疗诊断 / 处方建议
- 法律意见 / 司法文书生成
- 金融投资建议 / 信用评分
- 关键基础设施控制（电力、通信、交通）
- 影响儿童的自动化决策

未经授权使用本服务于上述场景产生的损失，**全部由您承担**。

## 调用频率与公平使用

- 单 Token RPM/TPM 限制由**计费档位**决定
- 单用户每日总消耗有上限（详见个人中心）
- 突发流量需提前 7 天申请白名单
- **公平使用**：占用过多公共资源（如长会话耗光分组配额）我们可单方面降权

## 我们如何检测违规

我们采用**最小化扫描**：仅在以下情况启用内容扫描：
- 收到**第三方投诉**（DMCA / 司法令）
- **风控触发**（异常调用模式 / 高额消耗 / 多次触发上游审核拒绝）
- **法律义务**（CSAM 反向哈希扫描属强制）

我们**不主动浏览您的对话内容**。详见 [`privacy-policy.md`](./privacy-policy.md)。

## 违规后果

| 严重程度 | 处理 |
|---|---|
| 一般（首次警告范围）| 邮件警告 + 限流 24h |
| 重要（重复违规 / 非恶意但造成影响）| 暂停账号 7 天 + 内部记录 |
| 严重（违法 / 欺诈 / 安全攻击）| 立即终止 + 已付费用不退 + 报警 + 配合调查 |
| 极严重（CSAM / 恐怖内容）| 立即终止 + 资金冻结 + 强制配合执法 |

## 举报

如发现他人违反本 AUP，请联系 [[abuse@example.com]] 并附证据（截图 / 链接 / 日志）。

合法的滥用举报享有**24 小时初步响应承诺**。
