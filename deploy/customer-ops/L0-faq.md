# L0 自助：FAQ + 自助工具

> 目标：**让 70% 用户在 L0 解决问题，无需人工介入**。

## FAQ 高频问题（每周 review，按工单 Top 列表更新）

### 1. 注册 / 登录

- **Q**: 注册邀请码哪里拿？
  **A**: 我们目前为邀请制 → 加入 Telegram 群 [[link]] 或购买入门套餐时附赠
- **Q**: 收不到验证码邮件
  **A**: 检查垃圾邮件 → 用 [@gmail.com / @outlook.com] 注册而非企业邮箱 → 联系 L1
- **Q**: 忘记密码
  **A**: /reset-password 输入邮箱 → 5 分钟内收到重置链接
- **Q**: 一个邮箱可以注册多账号吗？
  **A**: 不可。一邮箱一账号

### 2. 充值 / 计费

- **Q**: 支持哪些支付方式？
  **A**: USDT (TRC20) / Stripe (Visa/MC) / 支付宝 / 微信 / 兑换码
- **Q**: 充值不到账？
  **A**: 5 分钟内 90% 自动到账。超 30 分钟 → 工单附 TXID / 订单截图
- **Q**: 兑换码无效？
  **A**: 检查是否输错（区分大小写）→ 是否被使用 → 是否过期 → 联系 L1
- **Q**: 价格在哪看？
  **A**: 个人中心 → 模型价格表（按用户分组显示，已含分组倍率）

### 3. 调用 API

- **Q**: 401 Unauthorized
  **A**: 检查 Authorization header 是否 `Bearer sk-xxx` → 是否使用了已过期/已禁用的 key
- **Q**: 402 Payment Required
  **A**: 余额不足，去充值
- **Q**: 429 Rate Limit
  **A**: 触发 RPM/TPM 上限 → 提升档位 / 减小并发
- **Q**: 500/502 错误
  **A**: 上游临时不稳定，自动重试 3 次后仍失败 → 提交工单附 request_id
- **Q**: 怎么用 OpenAI SDK 调？
  **A**: 设 `base_url=https://api.example.com/v1`, `api_key=<your_key>` 即可。详见 [/docs](/docs)

### 4. 模型 / 用量

- **Q**: 支持哪些模型？
  **A**: 见模型列表页。OpenAI / Anthropic / Google / DeepSeek / Qwen 等主流模型全覆盖
- **Q**: 模型不可用 / 老报错？
  **A**: 检查模型分组（你当前分组是否有此模型权限）→ 状态页是否有上游故障公告
- **Q**: 我能看用量明细吗？
  **A**: 个人中心 → 用量记录，按时间/模型/Token 维度查询

## 自助工具（必备）

### 用量查询
个人中心 → 用量记录页：
- 时间线图（每日 token 数、消费）
- Top 5 模型
- 异常调用提醒（突增）
- 导出 CSV / JSON

### 余额预警
- 余额低于 $5 自动邮件提醒
- 可设自动充值（绑卡 / USDT 钱包）

### Token 管理
- 自助创建多 Token（项目隔离）
- 单 Token 设独立限速 / IP 白名单 / 过期时间
- 一键吊销

### 模型测试器
- 个人中心 → 模型测试器：浏览器内直接调任意模型，无需 SDK
- 用于调试 / 验证 model name / 探查响应

### Postman / Bruno 集合
导出已配置好的集合，新用户 1 分钟即可发出第一次调用：
- /v1/chat/completions OpenAI 兼容
- /v1/messages Anthropic 兼容
- /v1beta/models/:id Google 兼容

### 状态页
- [status.example.com]([[status.example.com]])
- 显示：网关 / 各上游分组 / 数据库 / 支付通道 状态
- 历史故障公告
