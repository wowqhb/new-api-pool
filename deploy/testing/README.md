# 测试 / 压测 / 混沌

## 目标

- **回归测试**：每次发版前自动跑核心 API 测试
- **压测**：k6 跑 1k QPS 稳定 5 分钟，找瓶颈
- **混沌**：主动注入故障，验证 SLO 不破

## 文件清单

- [`smoke/`](./smoke/) 烟雾测试（每次部署后自动跑，60s 完成）
- [`regression/`](./regression/) 完整回归测试（每周一次）
- [`load/k6/`](./load/k6/) k6 压测脚本
- [`chaos/`](./chaos/) 混沌实验脚本
- [`baseline.md`](./baseline.md) 性能基线（每月更新）

## 快速跑

```bash
# 烟雾测试（部署后必跑）
./smoke/run.sh

# 完整回归（含计费正确性 + 限速 + 缓存）
./regression/run.sh

# 压测（注意：在生产前必须先跑 staging）
k6 run --vus 100 --duration 5m load/k6/chat-completions.js

# 混沌（kill 一个网关实例）
./chaos/kill-one-gateway.sh
```

## 三层测试金字塔

```
                  ┌──────────────┐
                  │ 混沌（每月）   │  100 例
                  ├──────────────┤
                  │ 压测（每周）   │  500 例
                  ├──────────────┤
                  │ 回归（每天）   │  3000+ 例
                  ├──────────────┤
                  │ 烟雾（每次）   │  10 例
                  └──────────────┘
```

## CI 集成

- 每次 PR：跑 smoke + 一部分回归（标了 `@quick`）
- 主分支合并：跑全量回归
- 周二凌晨：跑压测 + 混沌
- 失败立即 P1 告警 → 阻塞发版
