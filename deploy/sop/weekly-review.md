# SOP：周一例会（30 分钟）

## 议程

| 时长 | 主题 | 负责人 |
|---|---|---|
| 5 min | 上周事故复盘（如有） | 值班 |
| 5 min | 关键指标 review（DAU/QPS/毛利） | 运营 |
| 5 min | 号池容量与寿命预警 | 运营 |
| 5 min | 客服热点（Top 3 工单） | 客服 |
| 5 min | 本周计划 / 阻塞 | 全员 |
| 5 min | OKR 进度 | 主管 |

## 必看数据（自动生成）

```bash
cd deploy/
bash bi/scripts/weekly-snapshot.sh > /tmp/weekly.txt
# 内容打印：DAU/请求数/毛利/Top 用户/Top 模型/号池容量/告警次数
```

## 决策项

每周必决：

- 号池补充计划（下周 / 下下周需要补多少号）
- 渠道亏本是否下架
- 用户分组政策调整（free 限速？vip 福利？）
- 下周值班排班

## 红线

下面任一项触发，本周必须解决（否则升级到月度复盘）：

- 任意 P0 故障未复盘
- SLO 连续 7 天未达标
- 毛利率连续 4 周下降
- 任意单日亏损 > $500
