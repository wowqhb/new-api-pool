# SOP：值班轮值

## 班次

- **工作日（10:00-22:00）**：A 班 / B 班 / C 班，每周轮换
- **工作日夜间（22:00-10:00）**：自动告警 + 应急联系（电话只在 P0/P1）
- **周末**：双人值班（白天 + 晚上）

## 工具配置

```yaml
# alertmanager.yml 已配 Telegram，但需要分级
P0/P1: -> Telegram + SMS + 电话（PagerDuty / 阿里云电话告警）
P2: -> Telegram 普通频道
P3: -> 每日摘要邮件
```

## 值班职责

每天值班期间：

- [ ] 看一遍 Grafana 总览看板（10 分钟）
- [ ] 处理任何 P0/P1 告警（必须 5 分钟内响应）
- [ ] 处理工单（24h 首次响应）
- [ ] 写交班日志（[`oncall-log.md`](./oncall-log.md)）

## 交班日志模板

```markdown
# Oncall Log: YYYY-MM-DD A班 - B班

## 上一班遗留问题
- [ ] 渠道 #123 自动禁用，原因排查中

## 本班处理
- 13:42 P2 告警：渠道 #456 连续失败 → 测了一下恢复了
- 15:30 用户工单：xxx → 已处理
- 19:00 推 v0.13.2 更新（灰度阶段）

## 给下一班
- [ ] 关注 v0.13.2 灰度状态（明天 24h 检查点）
- [ ] 渠道 #789 上游有公告说今晚维护
```

## 排班工具（推荐）

- 简单：飞书/钉钉日历共享
- 中等：[Better Uptime](https://betteruptime.com/) 自带 oncall（贵但好用）
- 重型：[PagerDuty](https://www.pagerduty.com/) / [Opsgenie](https://www.atlassian.com/software/opsgenie)

## 值班费

- 工作日值班：薪资计入
- 周末值班：双倍 / 调休
- 处理 P0/P1：额外加班费（按公司政策）

## 红线（值班期间禁止）

- ❌ 不能离开告警终端 30 分钟以上（中午饭、洗澡都要带手机）
- ❌ 不能喝酒（处理故障要清醒）
- ❌ 出差/旅行必须提前换班
- ❌ 不能拒绝接电话（P0 不接 = 升级到主管个人）
